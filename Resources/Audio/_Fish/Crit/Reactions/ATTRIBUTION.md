# Fish Crit / Reactions — human vocal library

Real human voice recordings (pain, moans, gasp, fall reactions), **CC0 / public domain only**.
Processed to mono OGG Vorbis 44.1 kHz (silence trim + dynaudnorm).

Detailed per-file mapping: `attributions.yml`.
