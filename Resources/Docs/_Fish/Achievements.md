# Исследование и перенос достижений SS13

Этот документ фиксирует проверяемые результаты аудита систем достижений SS13 и решения по их нативной адаптации для Fish Station на архитектуре SS14/Sunrise.

## Методика

1. Исследовать несколько активных и исторических форков SS13.
2. Зафиксировать источник, версию и точное условие каждого достижения.
3. Свести совпадающие достижения без потери происхождения.
4. Сопоставить условия с реально существующими событиями и системами SS14.
5. Исключать или адаптировать недоступные механики с обязательным обоснованием.
6. Реализовывать контент только после аудита архитектуры, persistence и UI текущего проекта.
7. Не копировать названия/описания 1:1: адаптировать под Fish/Sunrise с сохранением духа условия.

## Формат каталога

| Поле | Значение |
| --- | --- |
| ID | Стабильный идентификатор достижения в Fish Station |
| Название | Адаптированное название (не дословный copy SS13) |
| Описание | Локализуемое описание |
| Источник | Проект SS13, commit или версия и путь |
| Условие | Проверенное условие получения |
| Категория | Категория контента |
| Сложность | Оценка сложности |
| Прогресс | Бинарное либо измеряемый прогресс |
| Секретное | Правила видимости до получения |
| Интеграция SS14 | События и системы для серверной проверки |
| Решение | Перенос, адаптация, объединение или исключение |
| Статус | Состояние реализации |

## Текущий статус

- Найдено достижений до дедупликации: **510**
- Уникальных после name-dedup: **344**
- Перенесено (YAML-прототипы): **501**
- Адаптировано / Fish-original в каталоге: **501**
- Исключено как gameplay-награды: BeeCoin / cosmetic unlocks / role weighting (условия сохранены где уместно)
- Аудит архитектуры Fish/SS14: завершён
- Аудит SS13: активен (исторические builds + CM + смысловая дедупликация)
- Condition handlers: **полное покрытие** всех ключей `AchievementConditionKeys` (event-driven)
- Антиабуз: `oncePerRound`, cooldown, `minRoundSeconds`, ghost-gate, ignore suicide, kill только player-humanoid, shotgun-защита (`allowGenericTrigger` / progressTarget)
- Локали: нормальные name/desc (ru-RU + en-US); у `secret: true` до unlock показывается `secretDescription` — загадка/намёк без прямого спойлера условия
