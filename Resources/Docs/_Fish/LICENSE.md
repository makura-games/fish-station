# Лицензия контента `_Fish`

- [`LICENSE-FISH.TXT`](../../../LICENSE-FISH.TXT) — обзор
- [`LICENSE-FISH-MIT.TXT`](../../../LICENSE-FISH-MIT.TXT) — код / YAML / FTL / docs (MIT)
